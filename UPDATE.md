# Обновление дашборда — новые функции

Это обновление добавляет: произвольный период на графиках, активность и ER,
топ-постов с картинками и сортировкой в обе стороны, метки рекламы, раздел
коммуникации (клики по кнопкам связи), лучшее время для поста, и раздел
конкурентов (ручной трекер).

## Что нужно сделать

### 1. Миграция базы данных

В Supabase → **SQL Editor** → **New query** → вставьте содержимое файла
`supabase/migration_2.sql` из этого архива → **Run**. Это добавляет новые
таблицы и поля, не трогая уже собранные данные.

### 2. Обновите файлы в GitHub-репозитории

Замените файлы в вашем репозитории на те, что в этом архиве — можно просто
загрузить их через **Add file → Upload files**, GitHub предложит заменить
файлы с совпадающими путями (покажет разницу перед сохранением).

**Важно:** файл `vercel.json` в архиве содержит `REPLACE_WITH_CRON_SECRET` —
если у вас уже вписан реальный секрет в этом файле на GitHub, **не
перезаписывайте его этой версией**, либо сразу впишите свой секрет заново
после загрузки.

Остальные переменные окружения на Vercel менять не нужно — для новых функций
не требуется ничего нового.

### 3. Новый раздел «Конкуренты»

Отдельная страница `/competitors` — там нужно вручную добавить конкурентов
(имя, юзернейм) и периодически (когда заходите к ним в Instagram) вносить
снимок: дату, число подписчиков, ссылку на залетевший пост. Это осознанное
ограничение — Instagram API не отдаёт данные по чужим аккаунтам ни одним
легальным способом.

### 4. Проверка после деплоя

Откройте дашборд, переключитесь на «Свой период» и выберите даты — графики,
топ-постов и активность должны пересчитаться. Раздел «Реклама» и
«Конкуренты» изначально пустые — заполняются вручную через интерфейс.

## Ограничения, о которых стоит помнить

- **Межсетевые бенчмарки** (сравнение с рынком по Instagram/Telegram/VK/
  YouTube/Одноклассники/MAX) технически не реализуемы через официальные API —
  такие данные строятся на агрегированной базе тысяч чужих аккаунтов, которой
  ни у нас, ни у любого стороннего разработчика без такой базы нет. Для этого
  нужен платный сервис вроде LiveDune.
- **Лучшее время для поста** становится надёжным только когда накопится
  20+ постов в базе — на старте это будет случайным.
- **Аудитория (демография)** сильно ограничена тем, что Meta в принципе
  отдаёт через API — подробной картины, как в платных сервисах, через
  официальный Graph API не получить.
