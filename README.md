# Статистика Instagram и Telegram

Мини-версия LiveDune для своих аккаунтов. Сайт каждый день забирает статистику из
Instagram Graph API и Telegram, хранит историю в Supabase и показывает:

- **Обзор аккаунта**: подписчики и их динамика, подписки и отписки по дням, охват,
  просмотры, посещения профиля, клики по ссылке, ER и ERR с сравнением к прошлому периоду,
  типы публикаций, лучшие посты, лучшее время для публикаций.
- **Публикации**: плитка или таблица с обложками, фильтр по типу (Reels, карусели, фото),
  сортировка по любой метрике, карточка поста с динамикой по дням.
- **Stories** с охватом, просмотрами, ответами, переходами и выходами.
- **Аудиторию**: пол, возраст, города и страны подписчиков.
- **Сравнение аккаунтов** в одной таблице и на одном графике.
- **Telegram-каналы**, свои и конкуренты: подписчики, посты с просмотрами, реакциями и репостами,
  охват за 24 часа, ERR, ERR24, ER, лучшее время. По своим каналам ещё встроенная статистика
  Telegram: подписки и отписки, просмотры по дням, источники просмотров и подписчиков, уведомления.
- **Отчёты** в PDF (сводка, графики, лучшие посты, Stories, аудитория) и Excel (все цифры)
  по любым аккаунтам и каналам.

Хостинг Vercel и база Supabase работают на бесплатных тарифах.

## Где лежат пароли и ключи

В файле `.env.local` (он в `.gitignore` и на GitHub не попадает) и на Vercel в
Project Settings → Environment Variables. В README и в коде секретов нет.

| Переменная | Что это |
|---|---|
| `SITE_PASSWORD` | пароль для входа на сайт |
| `CRON_SECRET` | секрет для автоматического сбора; сделайте его отличным от пароля сайта |
| `SUPABASE_URL` | Project URL из Supabase → Project Settings → API |
| `SUPABASE_SERVICE_ROLE_KEY` | secret (service_role) ключ оттуда же |
| `IG_ACCESS_TOKEN` | System User token из Meta Business Manager |
| `TG_API_ID`, `TG_API_HASH` | ключи приложения Telegram с my.telegram.org (раздел «Telegram» ниже) |
| `IG_GRAPH_VERSION` | необязательно, по умолчанию `v24.0` |
| `NEXT_PUBLIC_TZ` | необязательно, часовой пояс публикаций, по умолчанию `Europe/Moscow` |

Аккаунты для сбора хранятся в базе и подключаются на сайте в разделе «Настройки»
(сайт сам видит все аккаунты, доступные токену). Переменная `IG_ACCOUNTS` больше не нужна.

## Как собирается статистика

| Когда (UTC / Москва) | Что |
|---|---|
| 09:00 / 12:00 | полный сбор: профиль, статистика по дням за 7 последних дней, публикации за 45 дней, Stories, аудитория; Telegram-каналы со встроенной статистикой |
| 03:00, 15:00, 21:00 / 06:00, 18:00, 00:00 | Stories Instagram и свежие посты Telegram (для охвата за 24 часа) |

Расписание задано в `vercel.json`. Vercel запускает задание в течение указанного часа.
Журнал каждого сбора виден в разделе «Настройки».

Ограничения Instagram, которые сайт обходить не может:

- Статистику по дням Instagram отдаёт только за последние 30 дней. Всё старше копит сайт.
- Сутки Instagram считает по тихоокеанскому времени: день «16 октября» идёт с 10:00 16-го
  до 10:00 17-го по Москве (зимой с 11:00).
- Число подписчиков за прошлые дни Instagram не хранит. Сайт замеряет его каждый день,
  а дни до первого замера восстанавливает по подпискам и отпискам. Такие дни приблизительные:
  Instagram иногда удаляет ботов из подписчиков, и в отписки это не попадает.
- Подписки, отписки и аудиторию Instagram отдаёт только аккаунтам от 100 подписчиков.
- Stories живут 24 часа. Последний замер бывает за несколько часов до исчезновения истории,
  поэтому итоговые цифры могут быть чуть больше.
- Обложки постов сайт копирует в Supabase Storage (бакет `ig-media`): ссылки Instagram
  перестают работать через несколько дней.

## Telegram

Каналы добавляются в «Настройках» → «Telegram-каналы»: ссылка или @username, отметка
«Свой» или «Конкурент», затем кнопка «История». Сайт работает в одном из двух режимов.

**Без ключей (включён сейчас).** Сайт читает публичные страницы `t.me/<канал>` и
`t.me/s/<канал>`: подписчики, посты, просмотры, реакции. Отсюда считаются ERR, ERR24, ER
(только по реакциям) и охват за 24 часа. Репостов, комментариев, подписок и отписок,
источников просмотров здесь нет, а просмотры больше тысячи Telegram на этих страницах
округляет (1,2K).

**Полный режим (через аккаунт Telegram).** Добавляются репосты, комментарии, точные
просмотры, а по своим каналам встроенная статистика Telegram: история подписчиков,
подписки и отписки по дням, просмотры канала по дням, источники, уведомления.
Каналы и накопленная история при переходе сохраняются.

Как включить полный режим:
1. На my.telegram.org → API development tools создайте приложение (платформа «Бот / сервер»).
   Скопируйте `App api_id` и `App api_hash`. Если сайт пишет «Слишком много попыток»,
   попробуйте позже с другой сети без VPN, например с мобильного интернета.
2. Добавьте их как `TG_API_ID` и `TG_API_HASH` на Vercel и в `.env.local`, пересоберите сайт.
3. Сделайте отдельный аккаунт Telegram админом своих каналов (права можно не давать).
4. На сайте: «Настройки» → «Telegram-каналы» → номер телефона → код из Telegram
   (и облачный пароль, если он включён).

Сессия аккаунта хранится в базе зашифрованной, ключ берётся из `TG_API_HASH`.
Если сменить `TG_API_HASH`, войдите в аккаунт на сайте заново.

Что важно знать:
- Конкурентов можно добавлять без подписки, если канал публичный. Закрытые каналы по
  ссылке-приглашению сайт не читает.
- Число подписчиков конкурента Telegram в прошлом не отдаёт, история копится со дня
  добавления. Посты и их просмотры подтягиваются за всё время.
- «Охват за 24 часа» сайт считает по своим замерам каждые 6 часов, поэтому для постов,
  вышедших до подключения канала, его нет.
- Подписки, отписки, источники и уведомления есть только у своих каналов, где аккаунт админ.

## Обновление с версии 1.0

База уже обновлена 18.10.2026 (выполнен `supabase/schema.sql`), история за 30 дней и все
публикации с обложками загружены. Осталось выложить код:

1. Откройте репозиторий сайта на github.com → **Add file → Upload files**.
2. Перетащите **содержимое** папки `ig-dashboard`, кроме `node_modules`, `.next` и `.env.local`.
   Файлы с теми же именами заменятся. Нажмите **Commit changes**.
3. Vercel сам пересоберёт сайт через пару минут.
4. На Vercel в Environment Variables проверьте, что `CRON_SECRET` задан.
   В `vercel.json` секрет больше не пишется: Vercel передаёт его сам.
5. Войдите на сайт заново (старый вход сбросится) и откройте «Настройки» → «Обновить сейчас».

## Установка с нуля

1. **Supabase.** New Project → SQL Editor → New query → вставьте весь `supabase/schema.sql` → Run.
   В Project Settings → API скопируйте Project URL и secret (service_role) ключ.
2. **Токен Meta.** В Business Manager создайте System User с доступом к Facebook-страницам,
   к которым привязаны Instagram-аккаунты, и выпустите токен с правами `instagram_basic`,
   `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement`.
3. **GitHub.** Создайте приватный репозиторий и загрузите туда файлы проекта
   (без `node_modules`, `.next`, `.env.local`).
4. **Vercel.** Add New → Project → репозиторий → Environment Variables (таблица выше) → Deploy.
5. На сайте: «Настройки» → «Подключить» → добавьте аккаунты → «Загрузить историю».

## Локальный запуск

```
npm install
npm run dev
```

Нужен файл `.env.local` с переменными из таблицы. Из России graph.facebook.com открывается
только через VPN или прокси.

## Если что-то не работает

- **На сайте ошибка про таблицу или колонку.** Выполните `supabase/schema.sql` ещё раз,
  он безопасен для повторного запуска.
- **В журнале сборов ошибка от Instagram.** Текст ошибки приходит прямо от Meta.
  Если Meta переименовала метрику, сайт пропустит её и сохранит остальные, а названия
  метрик правятся в `lib/instagram.ts`. Ошибка про токен значит, что токен отозван:
  выпустите новый и замените `IG_ACCESS_TOKEN` на Vercel.
- **Отчёт не скачивается.** Отчёт собирается в браузере. Обновите страницу и попробуйте
  ещё раз. Если ошибка повторится, её текст будет в окне отчёта.

## Устройство проекта

| Путь | Что внутри |
|---|---|
| `lib/instagram.ts` | запросы к Instagram Graph API |
| `lib/collector.ts` | сбор статистики в базу, восстановление подписчиков, копирование обложек |
| `lib/telegram.ts` | вход в аккаунт Telegram, каналы, посты, встроенная статистика |
| `lib/tgpublic.ts` | режим без ключей: чтение публичных страниц t.me |
| `lib/tgcollector.ts`, `lib/tgmetrics.ts` | сбор Telegram в базу и расчёт ERR, ER, охвата за 24 часа |
| `lib/dates.ts` | сутки Instagram и работа с датами |
| `lib/metrics.ts` | ER, ERR, сводки, лучшее время для публикаций |
| `lib/report/`, `lib/exportPdf.ts`, `lib/exportExcel.ts` | PDF и Excel |
| `app/api/` | API сайта и cron-адреса |
| `components/` | интерфейс |
| `supabase/schema.sql` | схема базы |
| `public/fonts/` | шрифт Inter для PDF (лицензия OFL в `Inter-OFL.txt`) |

Цвета графиков проверены на различимость при дальтонизме (синий, оранжевый, бирюзовый),
у каждого графика есть подписи и переключатель «Таблица».
